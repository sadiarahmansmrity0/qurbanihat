# QurbaniHat 🐐

A modern web application built with **Next.js** to simplify and showcase Qurbani-related services, events, and information.  
This project focuses on clean UI, smooth animations, and Firebase integration for dynamic features.

---

## 🚀 Features
- ⚡ **Next.js 13 App Router** for fast, scalable frontend
- 🎨 **Hero section with animations** for engaging landing page
- 🔥 **Firebase setup** for authentication and backend services
- 📂 **Modular folder structure** (`app`, `src`, `public`)
- 🌐 Responsive design for mobile and desktop
- 📝 Documentation files (`ATTRIBUTIONS.md`, `FIREBASE_SETUP.md`) included
